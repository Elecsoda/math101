```bash
python3 -m http.server 8000

```

## 结构

每个工具是一个自包含目录，入口为 `目录/index.html`。
根目录的 `ipad-touch-adapter.*`、`word-problem-tool.*`、`vendor/`
是各工具共享的资源，工具内以 `../` 引用。
